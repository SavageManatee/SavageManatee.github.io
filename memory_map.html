How To
Find the Slot Number (snum)

The slot number comes from the SEL event in the burn-in / diagnostic log output. Look for a line containing Memory # — the two characters immediately after it are the snum. 

ERROR: 08/11/26 05:04:52  Test failed due to SEL events
ERROR: 08/11/26 05:04:52  0007 01/01/70 02:22:57 MAJ SMI  Memory #d8  ECC limit reached, DIMM(0) 6f [a5 00 00]
ERROR: 08/11/26 05:04:52  ERRORS DETECTED --- aborting test
ERROR: 08/11/26 05:04:53  Errors during test:
	Error: Checks failed: SEL

In this example, Memory #d8 means the slot number is d8 — select it below once you've chosen the matching motherboard.
